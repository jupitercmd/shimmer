# Shimmer
### A stunning VFX modpack for Minecraft

Shimmer is a VFX modpack designed to be a drop-in replacement for Shine 3.0

## Build Types

* Full: Uses a older version of Minecraft but has the most mod compatibility. Use this for the best experience.
* Latest: Uses the latest version of Minecraft but has less mods
* Iris: Removes mods not compatible with Iris

## Installation

Grab the latest build from Releases. Next, simply import the file into the
Modrinth app or any other launcher that supports the mrpack format and launch your instance.
