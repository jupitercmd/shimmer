# Shimmer
### A stunning VFX modpack for Minecraft

Shimmer is a VFX modpack designed to be a drop-in replacement for Shine 3.0

## Installation

Grab the latest build from Actions. If you're confused, just navigate to the actions tab at the top, click on the first option in
the list with a checkmark, click on release in the sidebar and download the .mrpack file. Next, simply import the file into the
Modrinth app or any other launcher that supports the mrpack format and launch your instance.
